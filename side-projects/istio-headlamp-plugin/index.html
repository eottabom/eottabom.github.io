Istio Headlamp Plugin

Istio spec과 Ambient L7 정책 적용 위치를 Headlamp에서 바로 확인하는 플러그인

설정 하나를 보려고 매번 Edit를 여는 불편함에서 시작했다.

Artifact Hub에 배포했고, Headlamp 공식 External plugin 목록에도 올라가 있다.

View GitHubArtifact HubHeadlamp Plugins #1334

Why I Built It

  • spec이 안 보이는 상세 화면

    메타데이터와 상태만 보여줘서, DestinationRule 설정 하나를 확인하려 해도 매번 Edit를 열어야 함

  • 트래픽을 모두 막는 L7 정책

    Ambient 모드에서 L7 AuthorizationPolicy가 waypoint가 아닌 ztunnel에 걸리면 트래픽을 모두 막는데(fail closed), UI에서는 알 수 없음

  • 아무 데도 적용되지 않는 정책

    targetRef가 waypoint 없는 Service를 가리키면 정책이 적용되지 않는데, 겉으로는 정상처럼 보임

Architecture

Headlamp가 불러오는 플러그인이 Headlamp를 거쳐 클러스터 리소스를 읽기 권한으로만 조회하고, 그 결과를 리소스별 상세 화면, Ambient 분석 화면, Headlamp 기본 페이지의 Istio 섹션으로 그린다. 읽지 못한 정보는 추측하지 않고 화면에 그대로 알린다.

Request Flow

  1. 1

    메뉴 등록

    클러스터에 설치된 Istio CRD를 확인해, 있는 것만 사이드바와 라우트로 등록한다

  2. 2

    리소스 조회

    AuthorizationPolicy 같은 리소스를 열면 Headlamp를 거쳐 읽는다. Istio가 제공하는 API 버전을 차례로 시도한다

  3. 3

    Spec 그리기

    모델링한 필드는 타입별 섹션으로, 나머지는 재귀 렌더러로 그리고 마지막에 Full spec을 붙인다

  4. 4

    적용 위치 판정

    targetRef, selector와 Waypoint, Service, Namespace의 use-waypoint 라벨을 함께 읽어 L7 정책이 어디서 적용되는지 판정한다

  5. 5

    결과 표시

    판정 결과와 경고를 보여주고, 읽지 못한 정보가 있으면 판단할 수 없다고 표시한다

Approach

  • 리소스 레지스트리

    레지스트리 하나로 사이드바, 라우트, 목록, 상세 페이지를 모두 생성

  • 두 단계 렌더링

    주요 필드는 타입별 섹션으로, 나머지는 재귀 렌더러로 그려 더 새로운 Istio 버전의 필드도 빠짐없이 표시

  • 순수 함수 분석

    적용 위치 판정 같은 분석 로직을 순수 함수로 분리해 Istio 1.30.1 Ambient 클러스터 fixture로 테스트

  • 실화면 검증

    kind 클러스터와 Playwright E2E로 실제 Headlamp 화면에서 검증

Key Features

  • Spec 상세 화면

    리소스별 spec 섹션과 Full spec

  • Mesh Overview, Waypoints

    컨트롤 플레인, ztunnel, istio-cni 상태와 Waypoint 현황

  • L7 적용 위치 판정

    waypoint, ztunnel, 미적용 중 어디인지 판정하고 경고

  • 효과 없는 구성 경고

    엔드포인트 없는 ServiceEntry 같은 구성 표시

  • 기본 페이지 확장

    Service, Pod, Namespace 화면에 Istio 섹션 추가

  • 설치된 CRD만 노출

    클러스터에 있는 CRD만 사이드바에 표시

Design Principles

  • spec 우선

    모든 상세 페이지 끝에 Full spec을 둬서 리소스의 어떤 필드도 숨기지 않음

  • 추측하지 않기

    권한이 없거나 메시 상태를 읽지 못하면 적용 위치를 단정하지 않고 판단할 수 없다고 표시

  • 설치된 것만

    클러스터에 실제로 있는 CRD만 사이드바에 보여주고, Istio가 제공하는 모든 API 버전을 등록해 차례로 조회

Install and Distribution

  • Headlamp 데스크톱

    GitHub Release의 플러그인 tar.gz를 플러그인 디렉터리에 풀어서 설치

  • 클러스터 안 Headlamp

    GHCR 이미지 ghcr.io/eottabom/istio-headlamp-plugin을 init container로 붙여 플러그인 복사

  • Plugin Catalog

    Artifact Hub에 등록되어 데스크톱 Plugin Catalog에서 Istio로 검색해 설치

Compatibility

  • 지원 버전

    Istio 1.2x, 1.3x (networking.istio.io v1, v1beta1, v1alpha3 등 버전별로 이어서 조회)

  • Sidecar 전용 메시

    그대로 동작하고, ztunnel이 없으면 Ambient 화면이 그 이유를 설명

  • 관리형 Istio

    AKS add-on처럼 컨트롤 플레인 네임스페이스가 다른 환경도 istiod Deployment를 찾아 대응
