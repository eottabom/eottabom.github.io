Agent Space

여러 CLI 에이전트 세션을 한 화면에서 보고, 바로 입력까지 보내는 로컬 작업 공간

에이전트 여러 개를 같이 쓰다 늘어나는 터미널 창을 정리하려고 만들었다.

브라우저와 macOS 데스크톱 앱(Electron)에서 모두 쓸 수 있다.

Some parts of this project were developed with the assistance of AI tools.

View GitHub

Why I Built It

  • 창 관리 부담

    에이전트마다 터미널 창이 늘어나, 어떤 세션이 작업 중이고 어떤 세션이 입력을 기다리는지 한눈에 알 수 없음

  • 반복되는 창 전환

    같은 지시를 여러 에이전트에 보내거나 결과를 비교할 때마다 창을 옮겨 다녀야 함

Architecture

화면(브라우저나 Electron 창)과 로컬 Node 서버를 WebSocket 하나로 잇고, 서버가 PTY로 띄운 CLI 에이전트의 입출력을 그대로 중계한다. 세션 상태는 서버 메모리에만 두는 단순한 구조라 별도 저장소가 없다.

Request Flow

  1. 1

    세션 생성 요청

    툴바에서 에이전트와 옵션을 골라 WebSocket으로 생성 명령을 보낸다

  2. 2

    명령 변환

    Agent Resolver가 에이전트 종류와 자동 승인, 디버그, 추가 인자 옵션을 CLI 명령으로 바꾼다

  3. 3

    PTY 실행

    node-pty가 CLI 에이전트를 실제 터미널처럼 띄우고, Session Registry에 세션을 등록한다

  4. 4

    출력 스트리밍

    에이전트 출력이 WebSocket으로 화면의 xterm.js 터미널에 실시간으로 그려진다

  5. 5

    입력 전달

    터미널에서 친 키 입력이나 브로드캐스트 입력이 같은 길을 거꾸로 거쳐 PTY로 들어간다

Approach

  • PTY 실행

    node-pty로 에이전트를 실제 터미널처럼 실행하고, 출력은 WebSocket으로 화면에 실시간 전달

  • 터미널 화면

    React와 xterm.js로 세션별 터미널을 그리고, working, idle 상태를 도트 아바타로 표시

  • 화면과 서버 분리

    같은 화면을 브라우저와 Electron 앱에서 그대로 쓰도록 서버와 화면을 나눔

Key Features

  • 세션 관리

    Claude Code, Codex, Gemini, Bash 세션 생성, 종료, 재연결

  • 실시간 출력

    WebSocket으로 터미널 출력 스트리밍

  • 브로드캐스트

    같은 입력을 여러 세션에 한 번에

  • 상태 아바타

    working, idle 상태를 도트 아바타로

  • 레이아웃

    세로, 좌우 분할과 Ctrl + 숫자로 이동

  • 실행 환경

    브라우저와 macOS 앱(Electron)

How It Works

  • 세션 설정

    툴바의 에이전트 버튼을 누르면 설정 창에서 세션 이름, 작업 디렉터리, 자동 승인, 디버그 모드, 추가 CLI 인자를 정해 실행

  • 자동 승인 옵션

    에이전트별 옵션으로 바뀜 (Claude --dangerously-skip-permissions, Codex --full-auto, Gemini --yolo)

  • 터미널 관리

    헤더에서 세션 이름을 바로 고치고, 최소화하면 하단 독으로 내려가며, Kill All로 모든 세션을 한 번에 종료

Run and Distribution

  • 로컬 실행

    node-backend에서 npm run launch로 서버를 띄워 브라우저로 접속하고, npm run electron:dev로 데스크톱 앱 실행

  • 배포

    macOS(Apple Silicon) 앱을 GitHub Releases로 배포

  • 필요 환경

    Node.js 18 이상과 사용할 CLI 에이전트
