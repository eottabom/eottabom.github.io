Istio Headlamp Plugin

Headlamp에서 Istio 설정을 편집기 없이 읽고, Ambient 모드 구성을 확인하려고 만든 개인 플러그인

Active

Headlamp에서 Istio 리소스의 spec을 상세 화면에서 바로 보여주고, Ambient 모드의 Waypoint, ztunnel 상태와 L4/L7 정책 적용 위치까지 확인할 수 있는 플러그인. Istio 설정 하나 보려고 매번 Edit를 여는 불편함에서 시작한 개인 프로젝트로, Artifact Hub 배포와 Headlamp 공식 plugins 저장소 External plugin 목록 등재까지 진행.

Agent Space

Active
